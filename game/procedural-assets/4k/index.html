Eksik çizimlerin 4K asset paketi

Bu sayfada yalnızca hâlâ Canvas/JavaScript ile çizilen ve kendine ait görsel atlası bulunmayan oynanış görselleri bulunur.

Önceden görsel dosyası kullanan mob, kaynak, silah, tırpan, kask, oyuncu, köy, dekor ve yapı asset’leri bu pakete alınmaz ve olduğu gibi korunur. Paket; eksik mob animasyon atlaslarını, özel mineralleri, üretilen oyuncu görünümlerini ve Canvas aksesuarlarını içerir. Bu atlasların orijinal 4K PNG dosyaları korunur; oyun kullanırken bellekte daha hafif kopyalarını kullanır. Geçici parçacık/hasar efektleri ile arayüz çizimleri paket kapsamı dışındadır.

Yeni eksik atlasları üretmek için npm run build:missing-assets komutunu çalıştırın. Chromium kurulu değilse önce npx playwright install chromium komutunu kullanın.
